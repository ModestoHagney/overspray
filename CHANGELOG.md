# Change notes

What changed in each version of Overspray that went live. Newest at the top.

## v0.3.0 (28 Nov 2026)

### New
- Flip: Left/Right and Top/Bottom buttons under FLIP in PLACE, and in Edit > Flip, for images, shapes and text.
- Finishes: new presets based on the Gabir Motors spec tool, plus Flat, Candy and Velvet.
- Finish preview: the ball now reflects a race track, so finishes are easier to judge.
- Loading popup while the app starts up.
- Help > What's new opens these change notes.

### Fixed
- Spec maps no longer go matte in iRacing: clearcoat starts at 0 in every finish.
- Spec map is saved as 24-bit, as iRacing asks.
- Live: writes only the files that changed, keeps "on car" layers out of the spec map, writes TGAs bottom row first, and shows an amber warning when another app changed a file.
- The page no longer gets stuck half loaded.
- Tutorials open any hidden boxes they need, and say how to reopen a window you closed.
- Left/Right and Top/Bottom now have a capital on both words.
- Overspray checks for a new version every 5 minutes instead of 30.
